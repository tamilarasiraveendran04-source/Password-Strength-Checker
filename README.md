
# Password Strength Checker

## Project Description
Password Strength Checker is a simple Python application that checks whether a password is strong or weak.

## Features
- Checks minimum password length.
- Checks uppercase letters.
- Checks lowercase letters.
- Checks numbers.
- Checks special characters.
- Displays password strength.
- Provides suggestions to improve weak passwords.

## Technology Used
- Python 3
- Basic Python string operations

## How to Run
1. Install Python 3.
2. Open Command Prompt.
3. Navigate to the project folder.
4. Run the following command:

   python password_checker.py

5. Enter a password to check its strength.

## Expected Output
- Strong password: Displays STRONG.
- Weak password: Displays WEAK with improvement suggestions.
